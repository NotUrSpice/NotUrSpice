## Selected builds

### HaemoSync AI · Autonomous blood logistics
An OR-grounded proof of concept for a simulated five-hospital network. A greedy transshipment approach supports allocation decisions; an n8n workflow monitors inventory, uses Gemini for triage, and sends shortage alerts.

### JIT Procurement Agent · Constraint-aware sourcing
A procurement workflow that monitors inventory buffers, drafts RFQs, parses vendor replies, and weighs cost against lead time. In a test simulation across **3+ items**, it identified the relevant constraints and notified vendors and the operations manager.

### EngGfx Pro · Engineering graphics in the browser
